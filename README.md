# Tycoon City 3D

Мобильный 3D-тайкун/сити-билдер в браузере, без бэкенда и без CDN-зависимостей.

- **Активная игра**: `tycoon-v116.html` (+ `assets_v31/`, `vendor_v31/` — нужны ей для работы).
- **Куда смотреть в первую очередь**: `VISION.md` (вектор развития), `CHANGELOG_V116.md` и `ROADS_V116_NOTES.md` (история фиксов и решений).
- **`archive/`** — старые версии и заброшенные прототипы, см. `archive/README.md`.
