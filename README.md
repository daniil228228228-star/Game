# Tycoon City 3D

Мобильный 3D-тайкун/сити-билдер в браузере, без бэкенда и без CDN-зависимостей.

- **Активная игра**: `tycoon-v161.html` + `assets/` + `vendor/three_r128/` (разложенный вид присланной пользователем сборки `tycoon-v161-standalone.html`; `node tools/standalone.mjs build ...` собирает обратно в один файл).
- **Куда смотреть**: `CLAUDE.md` (как работать с кодом), `VISION.md` (вектор развития), `CHANGELOG_V161.md` (история изменений).
- **`archive/`** — старые версии и заброшенные прототипы, включая весь снимок v116 с его тестами и подробной историей фиксов (`archive/tycoon-v116/`), см. `archive/README.md`.
