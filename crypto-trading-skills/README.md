# crypto-trading-skills

Набор скиллов и скриптов для крипто-торговли, собранный и **проверенный на истории** в одной сессии Claude Code.
Главный вывод сразу: **прибыльной краткосрочной стратегии (часы и сутки) найти не удалось**; единственное, что держалось
во всех периодах с 2018 года, это медленный трендслединг по BTC/ETH (сделки на недели, без плеча). Это не гарантия и не способ получить «стабильный кэш».
Не финансовый совет.

## Что внутри
| Путь | Что это |
|---|---|
| `skills/trend-signal/` | Скилл + `trend_signal.py`: что говорят SMA50/100/200 по BTC/ETH сегодня и какая доля в рынке |
| `skills/futures-trade-calc/` | Скилл + `calc.py`: размер позиции, стоп/тейк, ликвидация для изолированных USDT-фьючерсов |
| `skills/edge-check/` | Скилл-методика: как проверять, есть ли у идеи реальное преимущество |
| `research/` | Все скрипты исследования (бэктесты, тесты Kronos/Chronos-2/TimesFM, GARCH, фандинг) |
| `THIRD_PARTY.md` | Чужие скиллы и модели: ссылки, вердикты, команды установки (код не копировался) |
| `CONTEXT.md` | Полный контекст: что делали, что нашли, цифры, состояние пользователя, правила общения |

## Как пользоваться
### Вариант 1: в Claude Code на компьютере
```bash
git clone https://github.com/daniil228228228-star/game
cd game && git checkout claude/crypto-trading-skills-6flgx2
mkdir -p ~/.claude/skills && cp -r crypto-trading-skills/skills/* ~/.claude/skills/
```
После перезапуска Claude Code скиллы можно вызывать по смыслу или командой (`/trend-signal`, `/futures-trade-calc`, `/edge-check`).
Скрипты скиллов лежат рядом с `SKILL.md`; если скилл скопирован в другое место, запускайте их оттуда.

### Вариант 2: без компьютера (Claude Code в вебе или приложении)
1. Откройте новую сессию с этим репозиторием и веткой `claude/crypto-trading-skills-6flgx2`.
2. Напишите: «Прочитай `crypto-trading-skills/CONTEXT.md` и `README.md`, потом продолжим». Claude восстановит контекст.
3. Просите по задаче: «какой сегодня сигнал по BTC/ETH» (запустит `trend_signal.py`), «посчитай сделку: шорт AVAX 9.04, маржа 2, плечо 10, стоп 2.5%, тейк 3.75%» (запустит `calc.py`).
   Заметьте: облачные песочницы могут блокировать Bybit и Binance (фьючерсы); публичные данные Binance Vision обычно доступны.

### Скрипты напрямую (нужен только Python 3.9+, без pip)
```bash
python3 skills/trend-signal/trend_signal.py            # сигнал BTC и ETH
python3 skills/trend-signal/trend_signal.py SOL        # другая монета
python3 skills/futures-trade-calc/calc.py --side long --entry 0.19 --margin 2 --leverage 10 --stop-pct 2 --tp-pct 4
```

### Воспроизвести исследование
```bash
cd research
python3 dl_daily.py           # дневки с 2017 (папка daily/)
python3 dl_hourly.py          # часовки за ~год (папка yr/)
python3 dl_funding.py         # фандинг Hyperliquid (папка fund/)
python3 research.py           # трендслединг, моментум, кэрри
python3 research2.py          # по периодам + сигналы сегодня
python3 ens.py                # комбинированное правило
python3 roll.py               # диапазон исходов за 8 месяцев
python3 swing.py              # более быстрые правила (дни)
python3 short.py              # время суток, день недели, опережение BTC, резкие движения
python3 scan24.py             # 24-часовые правила + фандинг
```
Скрипты Kronos/Chronos-2/TimesFM (`kr2.py`, `kr3.py`, `kr4.py`, `kt.py`) требуют `torch`, `einops`, `huggingface_hub`, `chronos-forecasting`,
`timesfm[torch]` и клона Kronos (`KRONOS_PATH=./Kronos`). Скрипты читают данные из папок рядом (`daily/`, `yr/`, `fund/`), их запускают из `research/`.
Данные в репозиторий не входят (см. `.gitignore`).

## Главные цифры
- Короткие правила (1ч-24ч, 8 монет, около года): **все в минусе после комиссий**; «следовать» и «против» обе проигрывают = нет преимущества.
- Модели: Kronos-small 49% направления на 24ч, Chronos-2 51%, TimesFM 49% (шум ±7%).
- Трендслединг BTC+ETH 50/50 (2018-2026): CAGR +45%, макс. просадка -47% (buy&hold: +25%, -81%); 8-месячные окна: медиана +18%, худший -36%.
- Кэрри по фандингу: BTC/ETH ~6% в год, мало и требует капитала.

## Предупреждения
Крипта рискованна. Никогда не давайте ключи с правом вывода, не подключайте неизвестные MCP/боты, плечо выше 10x почти всегда обнуляет депозит.
