## Пользователь и ограничения
- Пишет по-русски, **нет компьютера, только телефон**; хочет «стабильный кэш» и краткосрочные сигналы.
- Депозит на Bybit около **$2** (в рублях обсуждали 20 000 ₽ для длинной стратегии). Торгует вручную в приложении Bybit (фьючерсы, плечо до 20x).
- Просьба: отвечать просто, без перегруза терминами и таблицами (он сказал «я ничего не понял»).
- Облачная песочница: **Bybit (403) и Binance fapi/spot api (451) заблокированы**; доступны Binance Vision (`data-api.binance.vision`), OKX/Kraken/Coinbase/KuCoin/Bitget через curl, Hyperliquid (POST), CoinGecko, Hugging Face.
  Подмена User-Agent для обхода блокировок запрещена системой, не делать.
- Ключи/seed пользователь в сессии не давал; они не нужны. Электронную почту и личные данные не публиковать.

4. Тесты 24-часового горизонта (8 монет, ~374 дня, комиссия 0.055%/сторона + фандинг Hyperliquid): **17 из 18 правил без edge**; единственный кандидат
   (шорт после падения >10% за 7 дней) хрупок: t падает с 3.2 до 1.2 при учёте зависимости по дням, год был медвежьим (BTC -30%).
5. **Модели**: Kronos-small (210 прогнозов, 7 монет): направление 49% на 24ч, корреляция -0.02; Chronos-2: 51%; TimesFM 2.5: 49%. Прогноз сильного роста (>+3%) в среднем давал факт -0.39%. ADA (50 прогнозов): 50%. **Модели не дают сигнала.**
6. GARCH-волатильность: ориентир диапазона (ADA 24ч σ≈4%), но walk-forward корреляция с фактом слабая (~0.06): использовать только грубо.
7. Короткий горизонт (≈200 вариантов: время суток, день недели, опережение BTC, реакция на резкие часовые движения): **нет edge, стратегия и её противоположность обе в минус** (комиссия 0.11% всё съедает).
8. Долгий горизонт (дневки с 2017, 10 монет): **трендслединг BTC/ETH держится** (SMA 40-300 все положительные в 4/4 двухлетних периодов); недельный моментум по монетам не держится (вторая половина -4%); кэрри по фандингу ~6% (BTC/ETH), LINK 9.7%.
   Ансамбль SMA50/100/200, 50/50 BTC+ETH: CAGR +45%, Sharpe 1.07, просадка -47%. Быстрее (SMA5-10) хуже; шорты хуже лонгов.

   Не учтены: P2P/обмен 1-3% в каждую сторону, курс рубля, налоги, риск биржи.
9. Сигналы-ставки пользователю: ADA лонг 20x (вход 0.1902, SL 0.1864, TP 0.1978): **сработал по пользователю**, это один исход при шансе ~33%, не доказательство метода. Затем AVAX шорт около 9.0

## Ключевые выводы, которые нужно сохранять
- **Прибыльного краткосрочного сигнала нет.** Не называть ничего «прогнозом» или «сигналом с проходкой», только честные ставки с ограниченным убытком и пометкой «орёл/решка».
- «Проходка >70%» достижима только перекосом риска (тейк близко, стоп далеко) с отрицательным ожиданием: на SOL тейк +0.3% / стоп -2% давал 79% тейков и -0.11% на сделку.
- Не поощрять рост плеча и размера после выигрыша; максимум 10x, изолированная маржа, стоп и тейк в ордере.
- Для реального дохода честно предлагать навыки/фриланс (сайты, боты, автоматизация), трейдинг как хобби на копейки; трендслединг имеет смысл на накопленной сумме.
- Не финансовый совет; всегда проговаривать риски.
