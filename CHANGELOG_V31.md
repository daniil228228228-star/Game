# Changelog — Tycoon v31 (City Expansion & Strategy)

## 2026-09-20 — Импорт файла + аудит + roadmap

- Импортирован присланный пользователем файл (29.5MB, изначально 10915 строк) как
  новая актуальная линия разработки, заменяющая v19 в приоритете.
- Вынесены встроенные ассеты (`assets_v31/*.jpg|png`, идентичны ассетам v19 побайтово)

  По пути была допущена и исправлена ошибка экстракции (нечёткий поиск `<script>`-тега
  зацепил не тот блок и осиротил код boot-error-хендлера как видимый текст страницы) —
  исправлено переходом на точные, проверенные через `grep -n`, номера строк вместо
  эвристики. Проверено скриншот-сравнением до/после с оригиналом — идентично.
- Полный аудит файла (все 9849 строк) против 23-пунктового видения пользователя
  проведён через отдельного subagent-а. Результат: слой «строительная компания»
  (парк техники, база, контракты, тендеры, репутация) уже сделан хорошо и глубоко.
  Слой «город как живой организм» (население, районы-как-симуляция, гражданская
  инфраструктура с эффектом, стоимость земли, ветвление застройки, гражданская жизнь,
  растущая дорожная сеть) практически отсутствует — есть только именной скелет
  (`CITY_DISTRICTS`/`CITY_MARKETS`/`cityState`) без реальных данных симуляции.
- Составлен и отправлен пользователю roadmap из этапов A–G (жилой город →
  инфраструктура → дороги/трафик → экономика города → девелоперская стратегия →
  живой мир → полировка). Полный текст — в `TYCOON_V31_PLAN.md`.
