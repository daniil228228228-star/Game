# Архив

Здесь лежит всё, что не относится к активной разработке `tycoon-v116.html`
(корень репозитория), перенесено сюда без удаления — только для истории и
чтобы не путать будущих агентов/разработчиков файлами от заброшенных
концепций.

- **`prototypes/`** — самые ранние, полностью отдельные эксперименты:
  "EliteRoof 3D" (`eliteroof-index.html` + PWA-архив + его собственные
  `.github/workflows`/`.devcontainer`, тоже заброшенные), набор
  car-game/Babylon-экспериментов (`v2.html`..`v9-*.html`,
  `car-preview.html`), и самый первый `tycoon-original.html` (до v19).
- **`tycoon-original-app/`, `-assets/`, `-vendor/`, `-tests/`** —
  инфраструктура именно первого `tycoon-original.html` (ES-модули,
  Playwright-тесты на баланс/престиж/i18n для СТАРОЙ версии игры — не
  подходят для `tycoon-v116.html`, структура `STAGES` с тех пор другая).
- **`elite-idle-v2` … `elite-idle-v5-1`** — отдельная линия "idle"-игр,
  не связанная с тайкуном вообще.
- **`tycoon-lineage/`** — реальные предыдущие версии тайкуна
  (v19 → v31 → v36 → v55 → v62 → v63) с их changelog'ами/планами и
  собственными `assets_v19`/`vendor_v19`. **v116 — прямой потомок этой
  линии**, поэтому эти файлы полезны как история решений, даже когда сам
  код уже переписан. `assets_v31`/`vendor_v31` НЕ архивированы — они и
  сейчас нужны `tycoon-v116.html` для работы, оставлены в корне.

## Не забыть

redesign (unverified, agent hit weekly limit mid-edit)" — недоделанная
