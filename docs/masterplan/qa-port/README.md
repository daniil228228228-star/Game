# Проверка порта B01/B02, 2026-10-12

Основа: e00e94c, последняя загрузка владельца совпала побайтно. Chromium headless shell 150, программный WebGL, эмуляция iPhone 13.

Целевой masterplan-port.test.mjs: 24 проверки зелёные. Реальные DOM-нажатия, цены 350/750, запреты до оплаты, дорожные UUID, проход и возврат в ядро, тонкие ограждения, лимиты геометрии, главный сейв/перезагрузка, создание в радиусе 150 м, сброс, OLD_SAVE, ноль ошибок консоли. Сборка и roundtrip побайтно идентичны.

Общий прогон остановлен по просьбе владельца отправить готовый файл. Завершены 32/47 файлов, 29 зелёные. playthrough прерван; остальные 14 не запускались.

- district-infra: единственная ошибка — старое ожидание семи производственных шагов включило два независимых шага порта. Фильтр исправлен; повтор после исправления не выполнен. Все проверки реальной инфраструктуры/сохранения в этом запуске зелёные.
- factory-fleet: Open road union contour в старом объединителе; fallback меняет количество мешей при одном апгрейде. Такой класс нестабильности указан в исходном контексте; этот запуск на неизменённой основе отдельно не повторялся. Не объявлен исправленным.
- platform: собственный запуск теста использует /opt/pw-browsers/chromium, которого нет в окружении. platform-unit зелёный; браузерный контракт платформы этим запуском не проверен.

На реальном iPhone/Safari, GPU телефона, слышимый звук и ночное прохождение не проверено. Полный генплан и портовые здания не реализованы.
