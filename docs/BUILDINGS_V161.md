## 0. Инструменты и определения

- `node tools/showcase-v161.mjs [--stages 0,1|all] [--levels 1,5,10] [--house-levels 1-10] [--views front,side,top,iso] [--survey] [--also-legacy] [--tag bld] [--json f]` — ОДИН запуск браузера.
  Стройка каждого здания идёт через настоящую цепочку `createBuildingMesh` (BUILDERS + слои + v44 + v157 + gold tiers), здание ставится одно на траву (в кадр попадают только свет, земля и оно),
  регистрируется в настоящем реестре v83 тем же вызовом `registerRoot`, что делает `rebuildStatic`, и снимается 4 камерами (front, side, top, iso, 390x664 по пропорциям холста) в
  `scratchpad/shots/bld-<id>-L<n>-<view>.jpg`. `--survey` сначала собирает «позднюю» сцену (все этапы, все районы), печатает группы и коллайдеры и мерит/снимает живые объекты (лесопилка, бетон, рынок…).
  `--also-legacy` в том же запуске мерит и старый дом (`BuildingsV161.enabled=false`) — числа «до/после» из одной сцены. В конце печатается **PHYSICS REPORT**.
- `tests/buildings-physics.test.mjs` — один запуск, жёсткие проверки для семьи домов (этап 0/1 на всех уровнях 1..10 + мини-дом), `KNOWN ISSUE:` для остальных (это и есть очередь), `SHOTS_DIR=<dir>` пишет снимки домов 1/3/5/10.
- Общий измеритель: `tools/lib/buildings-probe-v161.mjs` (в страницу уходит `installProbe`).
- **Площадь основания F** — клетки 0,1 м, замкнутые вертикальными стенами (все треугольники с |n.y| < 0,35, заходящие не меньше 0,12 м в «торс» y 0,3..1,2 м, непрозрачные, не `v161Soft`; заливка снаружи, компоненты < 0,12 м² — столбы — отбрасываются).
  Заборы, живые изгороди, почтовый ящик, ступени, крыльцо — не основание.
- **Коллайдер C** — записи реестра v83 с флагом `player`, принадлежащие зданию (для живых групп — ближайшие не-деревья в пределах группа + 2,5 м).
- Метрики: overlap = |F∩C|/|F|, uncovered (м²) = F без C, outside (м²) = C без F, outsideMax (м) = самая дальняя клетка C-только от F; **sweep** = круг игрока (PLAYER_RADIUS 0,4) идёт с 8 сторон к центру через
  настоящую `resolvePlayerCircleCollisions` с коллайдерами только этого здания, `reach` = в скольких направлениях центр игрока оказался внутри F.
- «Висит/провалено» = min y видимых непрозрачных мешей (≠ 0 ± 5 см); `parked` = пулы под миром (y < -5), не считаются.
- Draw calls = число видимых мешей (один вызов на меш) и разница `renderer.info.render.calls` с моделью и без неё в кадре.

## 3. Очередь («по одному зданию»), с тремя главными проблемами

1. **Дома** — сделано (этот проход).
2. **Индустриальный кластер — СДЕЛАНО (6)** (было: P2; их видит игрок в первые 40 минут):
   (а) коллайдер — круг r 1,7–1,75: стена до 1,1 м и дыры (бетон: 0,94 м² стен не покрыты, заход с 1 стороны); (б) бетонный завод — 74 меша, бледная серо-белая гамма; (в) сарай цеха/плиты на 3 м² без связи с землёй, у шахт min y −0,2.
3. **Рынок: 7 прилавков + площадь** (P2): (а) нет коллизии — игрок проходит сквозь 7 прилавков; (б) одинаковые силуэты, неотличимые без значка; (в) площадь пустая, min y −0,03.
4. **Пригородный район: кольцо мини-домов** (P2): (а) без коллайдеров (проходятся сквозь, reach 5/8); (б) деревья/дома min y −0,13; (в) 96 мешей на район.
5. **Магазин (stage 2)** (P2→P3): (а) невидимая стена 1,43 м/7,5 м²; (б) кружок улучшения внутри коллайдера; (в) 98–129 мешей на здание, «roof tech» на крыше магазина.
6. **Склад / Логистический терминал (stage 3, 10)** (P3): (а) самый тяжёлый меш (142–157), (б) стена 1,53–1,67 м (10–14 м²), (в) выбеленная коробка, кружок улучшения внутри коллайдера (0,54 м).
7. **Заводы (stage 4, 5, 13)**: (а) растягивание по высоте на 18 % за уровень (9–10 м на L5), (б) кружки улучшения внутри коллайдера (0,68–0,72 м) и стена 1,18 м у завода, (в) 85–122 меша.
8. **Автопарк (fleet yard)**: (а) ограда проходима, (б) плоская плита без навеса/будки, (в) вход/въезд без разметки.
9. **Электростанция / водоканал** (ground-плиты): (а) нет самого здания — плита 0,5 м, (б) нет коллайдера и вывески-различителя, (в) не собираются без состояния V42.
10. **Офисы (stage 6, 7, 11, 14)**: (а) карандаши 15–20 м на L5, (б) 82–125 мешей, (в) стена до 1,04 м у stage 7/14.
11. **Башни (stage 8, 9, 12, 15)**: (а) 28–51 м на L5/L10, (б) корона на двух зданиях и gold дубли, (в) 67–93 меша.
12. Городские здания районов, базы, спецпроекты, стройплощадка, реквизит — измерить и разобрать по месту (нужна сцена с жильём/базой).
13. **Лесопилка v2 — физика СДЕЛАНА (6)**; было: только физика (внутренности не трогаем): кружок погрузки внутри коллайдера штабеля (выталкивает на 0,85 м), 2 из 8 заходов внутрь через открытый проём, круг r 2,15 даёт невидимую стену до 1,41 м.

## 4. Как переиспользовать на следующем здании

3. Добавить здание в жёсткие проверки `tests/buildings-physics.test.mjs` (по умолчанию `r.house` — семья в области; для следующей семьи расширить условие), `KNOWN ISSUE` строки этой семьи исчезнут.
