# Замена клеверной развязки: три варианта (эскиз для согласования, в игру НЕ внесено)

Правостороннее движение, игровые метры (1 игровой м = 2.5 м реальных). Все эскизы нарисованы `tools/sketch-interchanges-v161.py` на одной и той же сетке: M1 с запада на восток (EB по южной половине), M2 с севера на юг (SB по западной половине), центр узла (0, 0). Цвет линии = уровень эстакады, стрелки = направление ветви.

## Какую развязку менять и почему: I3 (M2 x M1)

- **I3 = «магистраль x магистраль»** (системная развязка). По нормам AASHTO (Green Book, гл. 10) / FHWA клеверный лист для пары шоссе считается устаревшим: петли R 20 игровых (50 м реальных, расчётная скорость ~40 км/ч) заставляют потоки шоссе переплетаться, пропускная способность петли ~1200 авт./ч против 2000+ у направленного съезда. Системные развязки строят направленными (стек, турбина, полупрямые).
- **I1 (M1 x Главный проспект)** - сервисная развязка «шоссе x улица»: клевер здесь допустим (малые потоки с проспекта), его можно перерисовать позже на парклo A4 / алмаз.
- Бонус: на I3 уже есть и М1, и М2 на эстакаде / в трубках, нет примыкающих кварталов (ближайший квартал z >= -160), переносить нечего, кроме колец съездов и деревьев.

Текущий вид: `interchange-0-current-I3.jpg` (8 съездов, 4 петли R 20 по 136 м + 4 внешних по 168 м, суммарно 1214 м, площадь x 130..370, z -360..-120 = 240 x 240 игровых = 600 x 600 м).

## Рекомендация

**Вариант B (турбина)**: самый компактный (550 x 550 м вместо 600 x 600), нет переплетения, все 12 манёвров прямые, всего 3 уровня (наш слой высот уже поддерживает настил над землёй; нужен ещё один промежуточный уровень). Запасной - C (меньше всего меняется). Вариант A дороже всего (4 уровня) и даёт самый плотный «лес» опор на телефоне.

Реализацию начинаю только после ответа владельца (какой узел менять - I3 по основанию выше или I1, и какой вариант).
