# Генплан C: перенос в игру — пошаговый план (2026-10-18)

Исходники генплана: данные `tools/masterplan/plan-C.json`, генератор `plan-c.mjs`, проверка `audit-plan-c.mjs`, картинки в `docs/masterplan-c/`, нормы в `docs/MASTERPLAN_C_PLAN.md` и `docs/ROAD_STANDARDS_V161.md`. Генплан утверждён владельцем 2026-10-18.

## 0. Главные решения

1. **Новая игра идёт на генплане C, старые сохранения остаются на плане B.** В сохранение добавляется поле `layoutV161: 'C'`. Если поля нет, это старое сохранение: оно грузится как сейчас (круг + план B), ничего не ломается. Перенос старых сохранений на C делается отдельным шагом позже и по согласию игрока.
2. **Центр совпадает.** Центральная площадь генплана C — это тот же хаб (0, 0), где уже стоит круговой перекрёсток. Ось Главного проспекта: x = 0; ось Центральной магистрали: z = 0. Масштаб тот же: 1 игровой метр = 2,5 настоящих.
3. **Дороги C — это данные.** Ни здание, ни стадия не «прокладывают» себе дорогу. Улицы, перекрёстки и развязки берутся из `plan-C.json`; у здания есть только короткий подъезд от своего участка к ближайшей улице плана. Старые дорожные системы (v59, v84, v86, v113, служебные дороги v66, коннекторы районов) в сохранении C выключаются флагом. В сохранении B они остаются как есть.
4. **Здания не переписываем, только переставляем.** Все наши строители (`buildings-v161`, `shop-v161`, `warehouse-v161`, `factory-v161`, `office-tower-v161`, `market-v161`, `sawmill-v161`, `plants-v161`, `yards-v161`, автопарк `FleetYardV161`, `site-v161`, `props-v161`, `characters-v161`, `plates-v161`) остаются. Меняются только позиция и разворот: они берутся из таблицы участков C, и дверь всегда смотрит на улицу.
5. **Город открывается постепенно.** Стартовый район — центр и привокзальная часть. Остальные районы открываются площадками-покупками, как платные площадки плана B. Механику площадок (`MasterplanV161`: `access` / `floor` / `clamp` / `syncBackdrop`, компилятор `compile-port.mjs`) переиспользуем.

## 2. Как рисовать (технически)

1. **Компилятор `tools/masterplan/compile-plan-c.mjs`** (по образцу `compile-port.mjs`): `plan-C.json` → `assets/plan-c-data-v161.js`. Что в нём:
   - геометрия проезжей части, тротуаров, разделительных полос, островков, бордюров (полигоны из графа, объединённые без щелей; скругления углов радиусом из норм);
   - разметка: оси, полосы, стоп-линии, «зебры», стрелки, «зубы»;
   - точки светофоров, знаков, фонарей, остановок;
   - развязки с высотами `y` (съезды и мосты);
   - проходимый пол: полигоны + функция высоты;
   - участки зданий: прямоугольник, дверь, угол поворота;
   - ландшафт: вода, пляж, лес, поля;
   - всё режется на ячейки 60 × 60 м.
2. **Слой `assets/plan-c-v161.js`** (живёт только в сохранении C):
   - каждая ячейка — 2–4 слитых меша (асфальт, разметка, тротуар/бордюр, зелень);
   - светофоры, фонари, деревья, знаки — instanced-меши (один вызов отрисовки на вид);
   - строится лениво вокруг игрока и камеры, дальние ячейки упрощены (LOD);
   - бюджет отрисовки: весь город C ≤ +60 вызовов на кадр сверх зданий.
3. **Высота.** Сейчас мир плоский (y = 0). Добавляется одна функция `groundHeightV161(x, z)`: 0 везде, кроме съездов, мостов, эстакад, пешеходных мостов и тоннелей. Её читают игрок (`updatePlayer`), камера, машины и коллизии. Без неё развязки и переходы не работают.
4. **Машины.**
   - Маршрут строится по графу C (Дейкстра по рёбрам с учётом полос и развязок) и подменяет `buildRoadRoute` в сохранении C.
   - Ядро v82 (следование полосе, дистанция, приоритеты) остаётся.
   - Кольца объезжаются как в `roundabout-v161.route()`.
   - Светофоры — один общий автомат фаз, машины останавливаются на стоп-линии.
   - Автобусы ходят по трём маршрутам с остановками.
5. **Пешеходы и игрок.** На «зебрах» машины уступают. Светофор пешеходам даёт зелёный по фазе. Пешеходные мосты и тоннели проходимы по высоте.

## 4. Что переиспользуем из старых наработок

- **Здания и анимации:** все строители v161, золотые уровни 6–10, стройплощадка, персонажи, таблички.
- **Площадки-покупки:** механика плана B (`access` / `floor` / `clamp`, сохранение флагов, тесты фаз 2–8).
- **Коллизии:** реестр v83 (`registerRoot`, прямоугольники стен), `PropsV161.obstacles()`.
- **Транспорт:** ядро v82 (`moveWaypointCityVehicle`, `samplePathV82`), пул машин `traffic-v161`.
- **Круг:** круговой перекрёсток `roundabout-v161` (геометрия и маршрут вокруг острова) — для кольца в центре C, параметры масштабируются под 2 полосы.
- **Экономика:** `STAGES`, цены, баланс-модель, `late-game`.
- **Тесты:** харнесс, пробы зданий, `road-audit`, `audit-plan-c`.

Что уходит в сохранении C: спиральные позиции (`stagePosition`), планировщик дорог стадий (v86 `plan()`, «колени»), служебные дороги v66, дороги районов v59/v70, планировщик коннекторов, придорожная мебель старой спирали (`v37LegacyRoadside`), фон-«коробки» на кольце r 78–83.

## 5. Риски и открытые вопросы к владельцу

1. **Расстояния.** Город C в ~4 раза больше нынешнего ядра; пешком от площади до промзоны около минуты. Нужен ли игроку транспорт (велосипед, машина) или быстрый переход по районам?
2. **Перенос старых сохранений** на C: делать (с компенсацией за расставленные здания) или старые игроки остаются на B?
3. **Направление движения.** Ядро сейчас держит машины у левого края (по часовой стрелке на кругу). Для C — правостороннее движение, как в России? Это меняет знак полосы в ядре v82 и всю разметку.
4. **Производительность на iPhone:** большой город с развязками — бюджет держу, но проверить можешь только ты.
