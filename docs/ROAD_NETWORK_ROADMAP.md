## 2. Что нарисовано «для вида» (не работает как настоящее)

1. Светофоры: головы на столбах есть, фаз нет (все дремлют).
2. Машины: ядро v82 водит их по старому графу, в раскладке C это не те улицы. Левостороннее движение ядра против правостороннего плана (открытый вопрос владельцу).
3. Остановки: столбы-навесы стоят, автобусов нет, «карман» только линия краской.
4. Пешеходные переходы: «зебры» нарисованы, машины не уступают.
5. Подземный переход под кольцом (PT3) и пешеходный мост через реку (FB2) не построены. Станция: платформы на насыпи, лестниц на них нет (подземные переходы PT1/PT2 есть).
6. Подъездной путь промзоны (шпур) начинается у стены насыпи на земле, на магистраль не заезжает (в плане уклон < 2,5 % невозможен на таком расстоянии).
7. Съезды клеверного листа и трубки: высоты по линейным узлам со сглаживанием; трубка I4 использует уклон до 6,5 % (М2 заканчивается на z 88 вместо 115).
8. Вода: плоский цвет без блика, берега плоские; фермы, корабли, поля без объёмов.
9. Фонари светятся ночью только головой и «пятном» на земле, настоящего освещения нет.

## 4. Тесты, которые нужно добавить позже
- Высоты для машин: ни одна машина не проваливается и не летит над настилом (после п. 1).
- Фазы светофоров: цикл, жёлтый, пешеходная фаза; нет двух зелёных на конфликтующих направлениях.
- Маршрут = асфальт: каждая точка маршрута на проезжей части или съезде.
- Нагрузка: 24 машины + 60 жителей при плане C, замер кадров на SwiftShader как относительный.
- Ночь: снимки в `SHOTS_DIR` на каждом типе узла (уже есть день и ночь).

## 5. Как работать с сетью
- Править `tools/masterplan/plan-c.mjs` (улицы, развязки; `audit-plan-c.mjs` должен проходить), `node tools/masterplan/plan-c.mjs`, затем `node tools/masterplan/compile-plan-c.mjs`.
- Высоты, насыпи, мосты: блок «6. rail / 6b. decks» в `compile-plan-c.mjs` (`SLOPE`, `DECKH`, `CLEAR`, `MOTOR_CROSS`, `structureDeck`).
- Картинки: `SHOTS_DIR=dir node tests/plan-c-roads.test.mjs` (вид сверху, вид телефона днём и ночью).
