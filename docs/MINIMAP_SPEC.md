# Мини-карта и большая карта (задание, 2026-10-18)

Владелец: «хочу мини-карту, чтобы ориентироваться, с возможностью вывести её на большой экран».

## Что делаем
1. **Мини-карта** в углу экрана (под верхними карточками HUD, не перекрывает кнопки, джойстик и кнопку действия): круглое или скруглённое окно ~110-130 px, север сверху или поворот по камере (переключатель), стрелка игрока, маркер цели (`currentGuidanceTarget()` / компас), точки платных площадок и открытых зданий, подпись района.
2. **Большая карта**: нажатие на мини-карту открывает полноэкранный слой (закрывается крестиком / повторным нажатием), перетаскивание и щипок-зум, список объектов (легенда с номерами как на генплане), кнопка «центрировать на мне», подписи улиц и районов, слои (дороги / транспорт / здания).
3. **Данные карты**: берутся из генплана C (`plan-C.json` / `assets/plan-c-data-v161.js`): вода, парки, зоны, улицы по классам, развязки, рельсы, остановки автобуса, пешеходные мосты, ориентиры. В режиме B (старые сохранения) карта рисует то, что есть (платные площадки плана B, дороги ядра).
4. **Рисование**: один раз в offscreen-canvas (кэш по сеткам 60 м), дальше только сдвиг и маркеры; никаких 3D-рендеров, не больше 1 лишнего вызова отрисовки; обновление маркеров <= 10 Гц.
5. **Стиль**: `assets/premium-ui-v161.css` (токены `--pu-*`, графит, золотой волосок), русский и английский текст, правила HUD: новая карточка добавляется одной строкой в `STACK` (`layoutTopV46`), тест `tests/hud.test.mjs` не должен ломаться.
6. **Тесты**: открытие/закрытие, зум и перетаскивание, маркер игрока совпадает с положением, нет перекрытий HUD на 390x664 и 360x640, нет 4xx/ошибок, затрат на кадр <= 0.3 мс (замер), сохранение настройки (север сверху / поворот).

## Не делаем сейчас
Плавающие панели квестов (по правилам игры скрыты); навигацию с линией маршрута по дорогам (после слоя высоты и графа маршрутов C).
