## 2. Недочёты, которые владелец прислал скриншотами (C1c; если агент Claude не успел)
1. Сплошная белая линия на проспекте рваная («лесенка»), распадается на блоки — сделать сплошной лентой достаточной ширины и правильных слоёв.
2. На скруглениях бордюров по асфальту тянется тонкая светлая диагональ «V» — остаток контура скругления; убрать (контур только по бордюру).
3. Опора эстакады стоит на краю полосы — перенести в разделитель/за бордюр (запас >= 0.5 м); разметка под мостом непрерывна; у настила нет карниза/толщины.
4. Камера на берегу уходит внутрь рельефа (бежевый купол) — починить, добавить тест облёта побережья.
5. Автобусные остановки стоят на газоне, фонарь внутри навеса, навес спиной к дороге — поставить на тротуар с карманом; далёкая разметка «волнистая».
6. **Игрок не может залезть на пешеходный мост** — воспроизвести реальным джойстиком (не телепортом) и починить; тест на 8 направлений.
7. Одинокая полоса, треугольник у «зебры», узкие круги — уже исправлено в C1b, проверить, что не вернулось.

## 3. Правила работы (важно)
- Ветка только `claude/new-session-v2u5sj`, без PR. Перед работой `git pull --rebase`, коммиты маленькие, сообщение коммита заканчивается строками `Co-Authored-By: ...` и `Claude-Session: ...` (если работаешь не Claude — свои).
- **Один исполнитель за раз.** Не запускай работу, пока другой агент не закончил (смотри `git log`, `docs/MASTERPLAN_C_PROGRESS.md`). Браузер для тестов один: `flock /tmp/claude-0/browser.lock <команда>`.
- Игру нельзя править «на глаз»: `tycoon-v161.html` — стопка слоёв (живо последнее определение; смотри `CLAUDE.md`). Новый код кладут в новые файлы `assets/*-v161.js` и подключают одной строкой.
- Не трогать: `assets/splash.png`, юридические тексты, таблицы данных и баланс (`tools/balance-v161.mjs`) без слова владельца, решения по Яндексу, рецепт текстур.
- Старые сохранения: поле `layoutV161` отсутствует = план B, ничего не должно измениться (подпись дорог OLD_SAVE 51 / -720375465 в тестах).
- Любое изменение сопровождай тестом и скриншотом; честно пиши, что НЕ проверено (реальный iPhone, ночь, звук).
- Запуск: `node tests/plan-c-roads.test.mjs` (`SHOTS_DIR=папка` пишет скриншоты), `node tools/shoot-plan-c.mjs OUT "имя:x,z,расстояние,угол,азимут"`, сборка двух версий `node tools/build-variants-v161.mjs` (`dist/tycoon-v161-zero.html` = новый план C, `dist/tycoon-v161-full.html` = витрина на плане B).
- Playwright нужен Chromium (`/opt/pw-browsers/chromium`), без него тесты не пойдут. Если у тебя нет браузера — работай только с данными/документами (`tools/masterplan/*`, `docs/*`) и пометь изменения как непроверенные.
