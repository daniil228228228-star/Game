# Исправления по аудиту: состояние передачи

База `473a78ac1740dd776d4de67c4d278144e04f4e98`. Изменения выполнены в отдельном рабочем снимке. Исходный каталог с незавершёнными C1c не изменялся. Полная браузерная приёмка не выполнена.

## Исправлено в данных

1. Маска земли не обрывает внешние нарисованные дороги на x300: конкретные дорожные/кольцевые/парковочные/портовые коридоры добавлены в `floor.extensions`. Река и море продолжают исключаться. Прямоугольник всей карты не расширялся.
2. В графе RIRO разрешает правые въезды/выезды и прямое движение по основной улице; запрещает левые, сквозные пересечения второстепенной улицы и развороты. Независимый геометрический тест проверяет также отсутствие ложных запретов.
3. P+R: подъезд до `(296,58)`, кольцо R8, участок до x308. В `(296,0)` — регулируемый узел с `coordination: 'I2'`. Восточный региональный подход заканчивается в x316 вместо x300: остаётся место для стоп-линии, зебры и машины. К центру есть направленный возврат без нарушения RIRO.
4. Клиппинг плоских треугольников исключает вырожденные фрагменты и проверяет окончательные округлённые координаты. Это устраняет ложное определение асфальта внутри островка нового кольца.
5. Аудит проверяет возвращение с парковки и все пары подходов RIRO; HARD-ошибка даёт exit code 1 также в `--json`.

## C4.1: исправленная физическая основа

- `arterialShuttleV82` использует сторону движения и для полос, и для дуг разворота. C правосторонний во всех четырёх направлениях, B сохраняет прежнюю траекторию.
- Компилятор экспортирует 234 профиля с ID: 214 рёбер и 20 съездов. `D.roadY` выбирает конкретную дорогу, а не верхнюю поверхность. Городские машины и служебный транспорт получают правильную высоту; при отсутствии опоры останавливаются.
- Для будущего роутера введён явный контракт C: `route.planC=true`, точки Vector3 с `roadId` и Y профиля. Сглаживание/смещение таких путей не повторяются; кэш учитывает высоту/ID. Старые пути без идентификатора сохраняют ближайший текущий уровень как временный fallback.
- Межуровневые ложные конфликты устранены в избегании городского/служебного транспорта, игрока/жителей, fleet rescue и столкновениях пешеходов с машинами. Одноуровневые конфликты сохраняются.
- Проверка: `node tests/plan-c-traffic-levels.test.mjs` — 135 097 утверждений, 60 заездов по всем съездам при 15/30/60 Гц. `node tools/check-plan-c-traffic-parity.mjs` — 1200 кадров B совпадают с исходной версией для четырёх владельцев движения.

## Что нельзя считать исправленным

- `buildRoadRoute`, районные петли и остальные владельцы движения ещё не переведены на направленные полосы C.
- Полное следование всех машин асфальту новых улиц ещё не подтверждено: их старые маршруты не заменены новым роутером.
- Реальная координация фаз P+R/I2, светофоры, пешеходные интервалы и стоп-линии C5 не реализованы.
- Пропускная способность клеверных переплетений не измерялась.
- Константа числа колец в браузерной части `plan-c-roads.test.mjs` обновлена до данных плана, но сам браузерный блок не выполнялся.

Владелец разрешил продолжить runtime-работу без Chromium с программными проверками. Полный прогон игры, WebGL, Safari/iPhone и живые маршруты не проверялись; программный рендер и VM не заменяют эти проверки. Выпуск «всё исправлено» по текущему состоянию невозможен: C4/C5 целиком не завершены.
