# Матрица поворотов plan C (2026-10-19, после исправлений аудита)

Граф учитывает RIRO: запрещены левые повороты, пересечение основной дороги со второстепенной и развороты вне колец. P+R имеет кольцо и регулируемый возврат. Длины — игровые единицы (×2,5 м); это топологическая матрица, НЕ доказательство проезда автомобиля или реализации C4/C5. direct — без городских поворотов для развязок; для I2 используется полный граф. Кольцевые переходы пока имеют нулевую стоимость, поэтому длины не включают реальную дугу кольца.
